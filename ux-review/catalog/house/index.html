Two radio choices above grouped topic lists

Room / category browser

Let guests use their physical room or an information category to find the same topic.

Information needed

  • Default mode: room
  • Room and category group labels
  • Shared topic ID
  • Room associations and category
  • Current group and return context

Behavior & accessibility

Native radio controls support keyboard arrows. Keep focus on the switch when changing modes. Retain the open topic and update its breadcrumb; Back returns to its current group.

When information is missing

Use Whole cottage for shared topics. Show an honest empty state when guidance is missing. Fresh loads default to By room; preserve session state without storage.
